# Курсовая по теме "поиск информации с подключением БД"
## Данный проект предназначен для интеграции с внешним сервисом. Трекер самолётов
Абстрактный класс APIAdapter - Шаблон для классов, работающих с api

Его потомки:

Api_Coord - Класс объекта, отвечающего за получение координат "квадрата" определенной страны

Api_Aeroplanes - Класс объекта, отвечающего за получение информации о самолетах в заданном "квадрате"


Класс DBManager для объекта,

Создает базу данных с информацией о самолетах в пространстве указанных стран. Его функции:

get_countries_and_aeroplanes_count - выдает информацию по общему количеству самолетов в пространстве
каждой страны из указанных

get_all_aeroplanes - выдает информацию по общему количеству самолетов в пространствах указанных стран

get_avg_speed - получает среднюю скорость по самолетам в пространстве каждой страны из указанных

get_aeroplanes_with_higher_speed - получает список всех самолетов, у которых скорость выше средней

get_aeroplanes_with_keyword - получает список всех самолетов, в позывном которых содержатся переданные в метод символы


Модуль utils содержит:

translate_text - переводчик с английского

end - определитель окончания слов в зависимости от числа

config - считывает параметры подключения к базе данных из ini - файла

conn_decorator - обертка функций DBManager-объекта, создающая соединение с базой и закрывающая его

Модуль main и его функция creation_of_aircraft_database 

Обеспечивают вывод информации в консоль
