# Курсовая по темам API и библиотека requests
## Данный проект предназначен для интеграции с внешним сервисом. Трекер самолётов
Абстрактный класс APIAdapter - Шаблон для классов, работающих с api

Его потомки:

Api_Coord - Класс объекта, отвечающего за получение координат "квадрата" определенной страны

Api_Aeroplanes - Класс объекта, отвечающего за получение информации о самолетах в заданном "квадрате"

Абстрактный класс Working_With_Files - Шаблон для объектов работающих с данными из файла,
характеризующими самолеты

Его потомок - WriteAddDel

Класс для объекта,

-удаляющего избранную информацию о самолетах из файла

-добавляющего информацию о новом самолете

-извлекающего информацию по самолетам из файла согласно критериям поиска

Модуль main и его функция working_with_the_user 

Обеспечивают диалог с пользователем

Программа позволяет получать информацию из API о самолетах в пространстве определенной страны:
- Список всех самолетов
- Топ N по скорости полета
- Найти самый быстрый и высоколетящий самолет
- Найти самолеты на земле
- Найти самолеты определенной страны-регистрации, определенной скорости, определенной высоты полета
- Удалять самолеты указанных стран регистрации
